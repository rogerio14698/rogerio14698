## Proyectos destacados

### Biblioteca DAW

<strong>Aplicacion Full Stack de gestion en Laravel + MySQL</strong><br>
Demo: <a href="https://biblioteca.rogerlab.es/biblioteca">biblioteca.rogerlab.es/biblioteca</a>

Sistema de gestion bibliotecaria con catalogo, prestamos, eventos culturales, noticias y area de usuario. Proyecto orientado a relaciones complejas, panel publico y experiencia completa de consulta.

**Lo mas destacable**

- Catalogo con mas de 500 registros y paginacion dinamica
- Login y registro de usuarios
- Eventos con fecha, ubicacion y detalle
- Noticias con multiples autores y roles editoriales
- Buscador integrado y diseno responsive

**Tecnologias**

`Laravel 12` `PHP 8.2` `MySQL` `Blade` `JavaScript Vanilla` `AWS EC2`

### API Pokemon Pokedex Shiny

<strong>Integracion de API REST con Laravel</strong><br>
Demo: <a href="https://apipokemon.rogerlab.es/pokemon/raichu">apipokemon.rogerlab.es/pokemon/raichu</a>

Pokédex construida en Laravel que consume PokeAPI para mostrar fichas completas de Pokemon con busqueda por nombre o ID, transformacion de JSON anidado y galeria de sprites normales y shiny.

**Lo mas destacable**

- Rutas limpias y semanticas
- Validacion de entrada por nombre o numero de Pokédex
- Tratamiento de datos JSON complejos desde API externa
- Componentes Blade reutilizables
- Filtrado de galeria en cliente

**Tecnologias**

`Laravel` `PHP` `API REST` `Blade` `JavaScript`

### AION

<strong>Modernizacion de plataforma empresarial en Laravel 12</strong><br>
Proyecto privado y confidencial.

Migracion de una aplicacion empresarial legacy a Laravel 12 y PHP 8.2, manteniendo compatibilidad con modulos y datos existentes. Incluye gestion de usuarios, permisos, proyectos, tareas, fichajes, vacaciones y mensajeria interna.

**Trabajo tecnico realizado**

- Reconstruccion del esquema relacional desde el dominio real
- Normalizacion de claves foraneas y tipos de datos
- Adaptacion de bootstrap y providers a la convencion actual
- Resolucion de conflictos de Composer
- Instalacion local limpia, segura y reproducible

**Resultado**

Base tecnica estable, lista para nuevas features, endurecimiento de seguridad y modernizacion progresiva del frontend.

---

### CMS Corporativo Bilingue

<strong>CMS administrable en Laravel orientado a negocio</strong><br>
Proyecto privado y reutilizable como producto propio.

Plataforma preparada para organizaciones que necesitan publicar y actualizar contenido sin depender del desarrollador para cada cambio. Incluye editor visual, menus dinamicos, gestion multiidioma, imagenes optimizadas y estructura SEO escalable.

**Lo mas destacable**

- Editor visual con TinyMCE
- Gestion de paginas, noticias, entrevistas y multimedia
- Login, control de usuarios y roles
- Sistema multiidioma
- Personalizacion rapida de identidad visual
